# scan-inbox

紙の書類を ScanSnap iX2500 でスキャンし、Claude が自動で整理する仕組み。

## 流れ

1. iX2500 のプロファイル「クラウドに送る」でスキャンする（PC不要）
2. ScanSnap Cloud が Google ドライブ「スキャン/00_受信箱」に PDF を保存する
3. 毎晩、Claude Code のルーティン「スキャン書類の整理」が受信箱を処理する
   - 名前を `YYYY-MM-DD_差出人_種類_要点.pdf` に付け直す
   - `20_書類/会社|個人/分類/年` に移動する（会社の会計書類は `10_会計/確認待ち/年月`）
   - ファイルの「説明」欄に目録（要約・キーワード・原本の扱い・仕訳案など）を書く
   - `90_目録` にその回の処理ログ（スプレッドシート）を作る
4. 会計書類は仕訳案を確認し、マネーフォワードに登録する（当面は人が登録）

ルーティンに渡している手順は [routine-prompt.md](routine-prompt.md)。変更したらルーティン側の設定も更新すること。

## 書類の取り出し方

Claude に頼む（例:「ベビーバンドの案内を出して」「2026年の医療費の領収書を一覧にして」）。
Claude は Google ドライブを次の順に探す。

1. `fullText contains '<語>'`（ファイル名・説明欄の目録・OCR文字をまとめて検索）
2. 必要なら `parentId` で分類フォルダに絞る
3. 説明欄の `[scan-meta v1]` を読んで、リンク・まとめたPDF・印刷などで渡す

## 原本の扱い

- 説明欄の「原本: 捨ててよい」なら破棄してよい
- 「MF登録まで残す」は、マネーフォワードに証憑付きで登録してから破棄する
- 「残す」（契約書・権利証・保険証券など）は原本も保管する
